# RBS Plataforma Comercial — V12

A V12 evolui a V11 para um núcleo comercial/ERP inicial.

## Módulos
- Dashboard comercial
- Clientes/CRM
- Orçamentos
- Catálogo e stock
- Movimentos de stock
- Pedidos
- Utilizadores administrativos
- PostgreSQL ou JSON local

## API nova
- `GET /api/dashboard`
- `GET/POST /api/customers`
- `GET/POST /api/quotes`
- `GET/POST /api/stock-movements`

A emissão fiscal, pagamentos e integração bancária não são simulados nesta versão.
