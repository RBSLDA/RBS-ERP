# RBS V11 — Plataforma Comercial com Dados Profissionais

## Entrou nesta versão
- PostgreSQL opcional e recomendado para produção.
- Fallback JSON preservado para desenvolvimento/local.
- Tabelas de utilizadores, produtos e pedidos.
- Palavra-passe administrativa armazenada com scrypt hash.
- Sessão administrativa HTTP-only.
- Upload de imagens PNG/JPEG/WebP até 4 MB para `public/uploads`.
- Volume Docker persistente para PostgreSQL, uploads e dados locais.
- Endpoint de pagamentos preparado, sem fingir que existe um gateway configurado.
- Criação de utilizadores administrativos autenticados.
- Migração/seed inicial dos produtos.

## Arranque local
```bash
npm install
node server.js
```
Sem `DATABASE_URL`, a aplicação continua usando `data/rbs.json`.

## Produção com PostgreSQL
1. Copie `.env.production.example` para `.env`.
2. Defina `POSTGRES_PASSWORD`.
3. Gere um hash:
```bash
node scripts/hash-password.js "SUA_SENHA_FORTE"
```
4. Coloque o resultado em `RBS_ADMIN_PASSWORD_HASH`.
5. Execute:
```bash
docker compose up -d --build
```

## Imagens
O painel pode enviar imagens via `POST /api/uploads`. O ficheiro é persistido no volume `rbs_uploads`.

## Pagamentos
`POST /api/payments/checkout` retorna explicitamente `501` até que um gateway real seja configurado. Nenhuma integração de pagamento fictícia foi criada.
